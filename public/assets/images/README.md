# Images Directory

Place all the images for your website in this folder.

Any image you place here will be accessible in your application using the `/assets/images/` path.

For example, if you add an image named `logo.webp` here, you can display it in your React components like this:

```jsx
<img src="/assets/images/logo.webp" alt="Logo" />;
// or using Next.js Image component (recommended)
import Image from "next/image";
<Image src="/assets/images/logo.webp" alt="Logo" width={100} height={100} />;
```
